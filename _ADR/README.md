# Architecture Decision Records

This directory is the canonical architecture-decision catalog for Odysseus.

Use one Markdown file per decision. A decision should contain a title, a
`Status` (`Proposed`, `Accepted`, `Rejected`, `Deprecated`, or `Superseded`),
a date, context, the decision, consequences, and—when relevant—replacement or
rollback notes.

Odysseus discovers this directory automatically. In the repository Overview,
select one or more decisions and choose **Plan selected**. The read-only
Planner creates an Epic and task DAG; nothing runs until the graph is approved.
