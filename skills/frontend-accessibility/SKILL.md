# Frontend Accessibility

Preserve the existing design system and interaction vocabulary. Use semantic elements before ARIA, maintain focus order and visible focus, and support keyboard-only operation. Design empty, loading, error, disabled, and narrow-screen states. Avoid color as the only signal. Verify the behavior at the user boundary and include an accessible-name assertion for critical controls.
