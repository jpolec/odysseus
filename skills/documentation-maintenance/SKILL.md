# Documentation Maintenance

Identify the reader and the exact action the document must enable. Verify commands, paths, names, links, defaults, and version claims against the repository. Prefer short runnable examples and progressive disclosure. Update adjacent navigation and version notes when needed. Do not describe features that are not implemented or screenshots that were not rendered from the current product.
