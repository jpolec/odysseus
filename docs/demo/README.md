# Odysseus walkthrough

`odysseus-90s.mp4` is a deterministic 90-second tour of the real Odysseus web
interface. It covers repositories, an outcome-first task, a dependency-aware
plan, Needs You, independent review, explicit artifact delivery, and the
engineering portfolio.

The recording uses only the disposable state produced by `scripts/demo.py`.
It does not invoke a coding agent, consume model tokens, or read the operator's
Odysseus state.

Rebuild both the film and poster from the repository root:

```sh
scripts/capture-web-demo.sh
```
